### 2025A 烟幕干扰弹（三方同口径可比，全圆柱严格遮蔽判据）

| 子问 | harness 8-02 | codex | 判定 | gap |
| --- | --- | --- | --- | --- |
| Q1 | 1.391642817891725 s | 1.3916426682674565 s | **平局** | 1.1e-5%（差 1.5e-7 s，落在复算容差 2.2e-4 s 内） |
| Q2 | **4.54288123958599 s** | 4.541442631127515 s | **harness 胜** | codex 落后 0.0317% |
| Q3 | 7.583258259760671 s | **7.589782871260711 s** | codex 胜 | harness 落后 0.0860% |
| Q4 | 11.49187489796957 s | **11.688904697082927 s** | codex 胜 | harness 落后 1.6856% |
| Q5（主指标） | 23.77147840823222 s | **25.098089441414814 s** | codex 胜 | harness 落后 5.2857% |

**这题是三题里唯一一条"评审引用的产物 == 清单登记的臂"的干净对照。**
harness 在最小规模的 Q2 上略胜；随着问题规模上升（Q3 单机三弹 → Q4 三机接力 →
Q5 五机十五弹），差距单调拉大到 5.29%。这是**搜索深度**的差距，不是建模口径差距：
两侧判据同为全圆柱严格遮蔽，全部申报值经独立复算偏差不超过 2.2e-4 s，**无人虚报**。

**ERRATUM（正向证据 + 一条自查漏网）**：harness 8-02 归档的"目标中心点"对照口径
1.4055095783283242 s 有几何 bug——判据在裁剪后的点到线段距离之外多加了 `-lam` 与
`lam-1` 两项，把云心投影落在导弹后方（含导弹已进入烟幕球）的时刻强制记为未遮蔽。
`ERRATUM.md` 给出修正值 **1.4350821019637348 s**，与 codex 同口径的
1.435082101964472 s 相差 6.0e-13 s，实质完全一致。主答案（全圆柱口径 Q1–Q5）不受影响。
这条 ERRATUM 是 harness 自己查出来的；但同一份 run 的"独立复核脚本"
`checks/q1_independent.py` 复刻了同一个投影窗口错误，因而与错误值互证通过——
**复核脚本与被复核脚本共用同一处几何假设时，复核就不是独立的**。

## 三、差距根因：搜索深度 vs 建模严谨度

**搜索深度：codex 领先，且随规模放大。**
2025A 从 Q2 到 Q5，harness 由领先 0.03% 变成落后 5.29%；2024C 滞销口径落后 2.66%
（登记臂）/ 1.02%（8-04 重跑），且 harness 自报 gap 3.96% 未证全局最优；2023D 登记臂
落后 11.81%。凡是"同口径、同模型、纯粹比谁搜得更狠"的地方，codex 都更好或不差。

**建模严谨度：harness 领先，但这份判卷给不了它分。**
harness 的产出里有 codex 没有的东西：全圆柱严格遮蔽判据的口径声明与三口径对照
（包围球 / 全圆柱 / 中心点）、自查出具 ERRATUM 并写回归测试、显式声明
`relative_gap` 与"未证明全局最优"、半价口径把可行域差异标注出来而不是拿去比高低、
2023D 的 1500 目标可执行排程构造。这些都不进 objective_value——本次判卷的指标全是
数值最优性指标，**严谨度在这套记分牌上是隐形的**。要让它可见，得先定义可判的严谨度
指标（口径声明完整性、gap 上界申报、复核独立性），并在下一次对照**开跑前**冻结。

**一条反例提醒**：harness 的"独立复核"在 2025A 中心点判据上失效了（复核脚本复刻了同
一个几何错误）。严谨度的优势建立在复核真正独立的前提上，这个前提本次被打破过一次。

## 七、复算方法

```powershell
# 重新生成 report.json（读 measurements.json，逐条回读磁盘核对，现场重算 gap 与排名）
python benchmarks/protocols/judges/retrospective_2026_blind.py

# 只校验：重算结果与磁盘上的 report.json 是否逐字节一致（有漂移则退出码 1）
python benchmarks/protocols/judges/retrospective_2026_blind.py --check

# 协议收口
python -m modelharness comparison audit --manifest benchmarks/protocols/2026-blind-codex-vs-harness.json
```

判卷公式（全部内联在 judge 脚本里，脚本 sha256 即参数 sha256）：

- `gap_vs_best_pct = (best - value) / |best| * 100`（direction=max）
  或 `(value - best) / |best| * 100`（direction=min）——分母**统一取最优臂的值**。
- `normalized_score`：max 取 `value/best`，min 取 `best/value`；1.0 = 该指标最优臂。
- `aggregate_normalized_score`：该臂参与的全部"计分且 head_to_head"指标的均值。
- 平局：`|value - best| <= tie_abs_tolerance`；2025A 时长类容差取 **2.2e-4 s**，
  即评审声明的独立复算最大偏差——低于这个量级的差异不构成优劣判定。
- verdict：单题臂按其 headline 指标的 outcome 定；跨题臂按 aggregate 是否最高定；
  逐指标胜负平明细一律写进 `verdict_detail`，不因 verdict 是单值而被吞掉。

`report.json` 里 25 个 observation 全部通过磁盘回读核对
（`source_verification.all_verified = true`）：每个数字都指向一个真实文件的真实 JSON
指针，2023D 登记臂那条还带 `derivation`（三年损失除以 3 年化），由脚本现场重算而非手抄。
